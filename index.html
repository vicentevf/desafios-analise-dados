Módulo 04: Consultas Básicas e Filtros em SQL

Exercícios práticos baseados no banco de dados fictício VendasDB

04.02. Tabelas Fato e Dimensão (VendasDB)

No nosso banco de dados:

  • Tabelas Fato (Eventos/Métricas): vendas e itens_venda (registram transações do negócio e métricas como valor e quantidade).
  • Tabelas Dimensão (Contexto/Entidades): clientes, produtos e categorias (contêm os atributos para filtrar e agrupar as métricas).
04.03 & 04.04. Primeiro SELECT & Colunas Específicas Básico
Escreva uma consulta que retorne apenas o nome, o e-mail e a cidade de todos os clientes cadastrados.
Ver Resolução SQL 
SELECT 
    nome, 
    email, 
    cidade 
FROM clientes;
04.05. Colunas com Alias Alias
Selecione a coluna nome_produto renomeando-a para Produto e a coluna preco_unitario renomeando-a para Preco_R$ na tabela de produtos.
Ver Resolução SQL 
SELECT 
    nome_produto AS Produto, 
    preco_unitario AS [Preco_R$] 
FROM produtos;
04.06, 04.07 & 04.08. Ordenando Dados ORDER BY
Listar todos os produtos ordenados primeiramente pelo categoria_id em ordem crescente e, em seguida, pelo preco_unitario em ordem decrescente.
Ver Resolução SQL 
SELECT 
    categoria_id, 
    nome_produto, 
    preco_unitario 
FROM produtos
ORDER BY 
    categoria_id ASC, 
    preco_unitario DESC;
04.09 & 04.10. TOP e TOP WITH TIES TOP / Limits
Selecione as 3 vendas de maior valor (valor_total) gravadas na tabela vendas. Inclua potenciais empates na 3ª posição usando WITH TIES.
Ver Resolução SQL 
SELECT TOP 3 WITH TIES 
    venda_id, 
    cliente_id, 
    valor_total 
FROM vendas
ORDER BY valor_total DESC;
04.11 & 04.12. WHERE e Operadores Lógicos Filtros
Retorne todos os clientes que residem no Brasil E na cidade de São Paulo.
Ver Resolução SQL 
SELECT * 
FROM clientes
WHERE pais = 'Brasil' AND cidade = 'São Paulo';
04.13 & 04.16. Operadores IN e NOT IN / NOT
Selecione todos os produtos que NÃO pertencem às categorias 1, 3 e 5.
Ver Resolução SQL 
SELECT * 
FROM produtos
WHERE categoria_id NOT IN (1, 3, 5);
04.15. Operador BETWEEN Intervalos
Encontre todas as vendas realizadas no primeiro trimestre de 2026 (entre 2026-01-01 e 2026-03-31).
Ver Resolução SQL 
SELECT * 
FROM vendas
WHERE data_venda BETWEEN '2026-01-01' AND '2026-03-31';
04.17 & 04.18. Concatenando colunas & LIKE Texto
Exiba uma coluna contendo a frase formatada: "Cliente [Nome] mora em [Cidade] - [Pais]" para todos os clientes cujo nome comece com a letra 'A' or 'M'.
Ver Resolução SQL 
SELECT 
    'Cliente ' + nome + ' mora em ' + cidade + ' - ' + pais AS descricao_cliente
FROM clientes
WHERE nome LIKE 'A%' OR nome LIKE 'M%';
