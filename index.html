Módulo 04: Consultas de Seleção e Filtros em SQL

Exercícios práticos aplicados sobre o banco de dados VendasDB

04.03. Primeiro SELECT Básico

Escreva uma consulta que retorne todas as colunas e todas as linhas da tabela de clientes.

SELECT * 
FROM clientes;
04.04. Selecionando colunas específicas Básico

Selecione apenas as colunas nome_produto, preco_unitario e estoque da tabela de produtos.

SELECT nome_produto, preco_unitario, estoque 
FROM produtos;
04.05. Colunas com Alias Básico

Selecione a coluna nome renomeando para "Nome do Cliente" e a coluna email para "Contato".

SELECT 
    nome AS [Nome do Cliente], 
    email AS Contato 
FROM clientes;
04.06. Ordenando Colunas Ordenação

Liste todos os produtos exibindo nome_produto e preco_unitario, do mais caro para o mais barato.

SELECT nome_produto, preco_unitario 
FROM produtos 
ORDER BY preco_unitario DESC;
04.09. Selecionando TOP linhas Limitação

Traga os 3 produtos de maior valor na tabela de produtos.

SELECT TOP 3 nome_produto, preco_unitario 
FROM produtos 
ORDER BY preco_unitario DESC;
04.11. Selecionando WHERE Filtros

Filtre e retorne apenas as vendas onde o método de pagamento seja 'Pix'.

SELECT * 
FROM vendas 
WHERE metodo_pagamento = 'Pix';
04.13. Operador IN Filtros

Traga todas as vendas onde o método de pagamento seja 'Pix' ou 'Cartão de Crédito'.

SELECT * 
FROM vendas 
WHERE metodo_pagamento IN ('Pix', 'Cartão de Crédito');
04.15. BETWEEN Filtros

Liste todas as vendas realizadas entre 01/02/2026 e 30/04/2026.

SELECT * 
FROM vendas 
WHERE data_venda BETWEEN '2026-02-01' AND '2026-04-30';
04.17. Concatenando colunas Texto

Concatene o nome e a cidade do cliente no formato "Nome - Cidade".

SELECT 
    CONCAT(nome, ' - ', cidade) AS cliente_localizacao 
FROM clientes;
04.18. LIKE Texto

Liste os clientes cujo nome começa com a letra 'C'.

SELECT * 
FROM clientes 
WHERE nome LIKE 'C%';
