1. Listagem de Clientes e Renda Anual Básico

Selecione o primeiro nome (FirstName), sobrenome (LastName), e a renda anual (YearlyIncome) de todos os clientes da tabela DimCustomer que possuem uma renda anual superior a $80,000. Ordene pelo sobrenome em ordem alfabética. 

SELECT 
    FirstName,
    LastName,
    YearlyIncome
FROM dbo.DimCustomer
WHERE YearlyIncome > 80000
ORDER BY LastName ASC;
2. Total de Vendas por Categoria de Produto Intermediário

Calcule o valor total de vendas (SalesAmount) agrupado pelo nome em inglês da categoria do produto (EnglishProductCategoryName). É necessário realizar a junção das tabelas FactInternetSales, DimProduct, DimProductSubcategory e DimProductCategory. 

SELECT 
    pc.EnglishProductCategoryName AS Categoria,
    SUM(fis.SalesAmount) AS TotalVendas
FROM dbo.FactInternetSales fis
INNER JOIN dbo.DimProduct p ON fis.ProductKey = p.ProductKey
INNER JOIN dbo.DimProductSubcategory ps ON p.ProductSubcategoryKey = ps.ProductSubcategoryKey
INNER JOIN dbo.DimProductCategory pc ON ps.ProductCategoryKey = pc.ProductCategoryKey
GROUP BY pc.EnglishProductCategoryName
ORDER BY TotalVendas DESC;
3. Vendas por Revendedor e Território Intermediário

Exiba o nome do revendedor (ResellerName), a região do território (SalesTerritoryRegion) e o valor total acumulado das vendas (SalesAmount) para cada revendedor da tabela FactResellerSales. Exiba apenas os revendedores cujo total de vendas ultrapasse $100,000. 

SELECT 
    r.ResellerName,
    st.SalesTerritoryRegion,
    SUM(frs.SalesAmount) AS TotalVendas
FROM dbo.FactResellerSales frs
INNER JOIN dbo.DimReseller r ON frs.ResellerKey = r.ResellerKey
INNER JOIN dbo.DimSalesTerritory st ON frs.SalesTerritoryKey = st.SalesTerritoryKey
GROUP BY r.ResellerName, st.SalesTerritoryRegion
HAVING SUM(frs.SalesAmount) > 100000
ORDER BY TotalVendas DESC;
4. Ranking de Vendas de Funcionários por Ano Avançado

Utilizando a função de janela (Window Function) DENSE_RANK(), crie um ranking dos funcionários (DimEmployee) com base no total de vendas realizadas na tabela FactResellerSales para cada ano de pedido (CalendarYear da tabela DimDate). 

WITH VendasPorFuncionario AS (
    SELECT 
        d.CalendarYear,
        e.FirstName + ' ' + e.LastName AS NomeFuncionario,
        SUM(frs.SalesAmount) AS TotalVendas
    FROM dbo.FactResellerSales frs
    INNER JOIN dbo.DimEmployee e ON frs.EmployeeKey = e.EmployeeKey
    INNER JOIN dbo.DimDate d ON frs.OrderDateKey = d.DateKey
    GROUP BY d.CalendarYear, e.FirstName, e.LastName
)
SELECT 
    CalendarYear,
    NomeFuncionario,
    TotalVendas,
    DENSE_RANK() OVER (PARTITION BY CalendarYear ORDER BY TotalVendas DESC) AS Ranking
FROM VendasPorFuncionario
ORDER BY CalendarYear, Ranking;
5. Análise de Vendas Cumulativas (Running Total) Avançado

Escreva uma consulta que retorne o ano/mês do pedido e calcule a soma diária das vendas na tabela FactInternetSales, adicionando uma coluna com o total acumulado das vendas ao longo do tempo (Running Total). 

SELECT 
    d.FullDateAlternateKey AS Data,
    SUM(fis.SalesAmount) AS VendasDoDia,
    SUM(SUM(fis.SalesAmount)) OVER (ORDER BY d.FullDateAlternateKey) AS TotalAcumulado
FROM dbo.FactInternetSales fis
INNER JOIN dbo.DimDate d ON fis.OrderDateKey = d.DateKey
GROUP BY d.FullDateAlternateKey
ORDER BY d.FullDateAlternateKey;
6. Distribuição Geográfica de Clientes por País Básico

Conte a quantidade total de clientes (DimCustomer) registrados por país (EnglishCountryRegionName da tabela DimGeography). Exiba os resultados ordenados do país com maior número de clientes para o menor. 

SELECT 
    g.EnglishCountryRegionName AS Pais,
    COUNT(c.CustomerKey) AS TotalClientes
FROM dbo.DimCustomer c
INNER JOIN dbo.DimGeography g ON c.GeographyKey = g.GeographyKey
GROUP BY g.EnglishCountryRegionName
ORDER BY TotalClientes DESC;
7. Produtos sem Nenhuma Venda Registrada Intermediário

Identifique todos os produtos acabados (FinishedGoodsFlag = 1) na tabela DimProduct que nunca foram vendidos pela internet (ausentes na tabela FactInternetSales). Exiba o código (ProductAlternateKey) e o nome do produto (EnglishProductName). 

SELECT 
    p.ProductAlternateKey,
    p.EnglishProductName
FROM dbo.DimProduct p
LEFT JOIN dbo.FactInternetSales fis ON p.ProductKey = fis.ProductKey
WHERE p.FinishedGoodsFlag = 1
  AND fis.ProductKey IS NULL
ORDER BY p.EnglishProductName;
8. Desempenho de Vendas vs Cota Anual (Quota) Intermediário

Compare o valor total de vendas atingido por cada funcionário (FactResellerSales) com a sua cota anual estipulada (FactSalesQuota) para o ano de 2013. Exiba o nome do funcionário, a cota total, o total vendido e o percentual atingido da cota. 

WITH Vendas2013 AS (
    SELECT 
        frs.EmployeeKey,
        SUM(frs.SalesAmount) AS TotalVendas
    FROM dbo.FactResellerSales frs
    INNER JOIN dbo.DimDate d ON frs.OrderDateKey = d.DateKey
    WHERE d.CalendarYear = 2013
    GROUP BY frs.EmployeeKey
),
Cotas2013 AS (
    SELECT 
        EmployeeKey,
        SUM(SalesAmountQuota) AS TotalCota
    FROM dbo.FactSalesQuota
    WHERE CalendarYear = 2013
    GROUP BY EmployeeKey
)
SELECT 
    e.FirstName + ' ' + e.LastName AS Funcionario,
    c.TotalCota,
    ISNULL(v.TotalVendas, 0) AS TotalVendas,
    ROUND((ISNULL(v.TotalVendas, 0) / c.TotalCota) * 100, 2) AS PercentualAtingido
FROM Cotas2013 c
INNER JOIN dbo.DimEmployee e ON c.EmployeeKey = e.EmployeeKey
LEFT JOIN Vendas2013 v ON c.EmployeeKey = v.EmployeeKey
ORDER BY PercentualAtingido DESC;
9. Comparativo de Vendas Mês a Mês (MoM Growth) Avançado

Utilize a função de janela LAG() para calcular o total de vendas na internet (FactInternetSales) de cada mês, comparado ao mês anterior, exibindo o valor de vendas do mês atual, do mês anterior e a variação percentual mensal. 

WITH VendasMensais AS (
    SELECT 
        d.CalendarYear,
        d.MonthNumberOfYear,
        d.EnglishMonthName,
        SUM(fis.SalesAmount) AS VendasAtuais
    FROM dbo.FactInternetSales fis
    INNER JOIN dbo.DimDate d ON fis.OrderDateKey = d.DateKey
    GROUP BY d.CalendarYear, d.MonthNumberOfYear, d.EnglishMonthName
)
SELECT 
    CalendarYear,
    MonthNumberOfYear,
    EnglishMonthName,
    VendasAtuais,
    LAG(VendasAtuais, 1) OVER (ORDER BY CalendarYear, MonthNumberOfYear) AS VendasMesAnterior,
    ROUND(((VendasAtuais - LAG(VendasAtuais, 1) OVER (ORDER BY CalendarYear, MonthNumberOfYear)) 
            / LAG(VendasAtuais, 1) OVER (ORDER BY CalendarYear, MonthNumberOfYear)) * 100, 2) AS VariacaoPercentual
FROM VendasMensais
ORDER BY CalendarYear, MonthNumberOfYear;
10. Hierarquia Organizacional de Funcionários (CTE Recursiva) Avançado

Escreva uma Expressão de Tabela Comum Recursiva (WITH CTE) utilizando a tabela DimEmployee para mapear a árvore hierárquica da empresa, mostrando o nome do funcionário, o nome do seu gestor direto (ParentEmployeeKey) e o seu nível dentro da estrutura organizacional (nível 1 para a chefia principal). 

WITH HierarquiaFuncionarios AS (
    -- Âncora: Funcionários sem gestor (Nível Superior)
    SELECT 
        EmployeeKey,
        ParentEmployeeKey,
        FirstName + ' ' + LastName AS NomeFuncionario,
        CAST(NULL AS NVARCHAR(101)) AS NomeGestor,
        1 AS Nivel
    FROM dbo.DimEmployee
    WHERE ParentEmployeeKey IS NULL

    UNION ALL

    -- Membro Recursivo: Subordinados
    SELECT 
        e.EmployeeKey,
        e.ParentEmployeeKey,
        e.FirstName + ' ' + e.LastName AS NomeFuncionario,
        h.NomeFuncionario AS NomeGestor,
        h.Nivel + 1 AS Nivel
    FROM dbo.DimEmployee e
    INNER JOIN HierarquiaFuncionarios h ON e.ParentEmployeeKey = h.EmployeeKey
)
SELECT 
    Nivel,
    NomeFuncionario,
    ISNULL(NomeGestor, 'CEO / Direção') AS GestorDirecto
FROM HierarquiaFuncionarios
ORDER BY Nivel, NomeFuncionario;
